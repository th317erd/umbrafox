# Blur Source Controls

> **Archived project record.** This page preserves dated project evidence and its original status. Source, tests, and current Umbrafox documentation outrank it.

## Purpose And Authority

Continue the owner's authorized laptop performance investigation. The preceding
DMABuf pixel gate found a reproducible eleven-component, one-level difference
between two fresh blurred video canvases with the new import path OFF. This
diagnostic characterizes that difference; it does not relax pixel acceptance.
No browser engine change, default change, desktop action or ON run is allowed
in this phase. The broader rendering/layout/CSS/JavaScript goal remains open.

## Territory And Contract

New artifact siblings reuse `captureLocalWorkload` for native private-directory
receipts, 120-second work/cleanup envelope, resource bounds, owned process
cleanup and raw reply preservation. Reuse the pinned package and media, the
existing `pixelRequest` parent transport, `observePixels` native observer and
installation verifier. Do not change their frozen consumers or saved evidence.

One paused video frame at 0.5 seconds feeds twelve ordered case pairs:
unfiltered video, blurred video, one frozen VideoFrame, a full-size raster copy,
deterministic full-size synthetic RGBA, then blurred video again. Each has a
default context and a `willReadFrequently:true` control. Every pair uses two
fresh 320x180 canvases; detached source canvases are not target observations.
VideoFrame and raster/synthetic sources stay fixed across their two context
variants. Hash raster/synthetic inputs before and after to detect mutation.

Native observations occur after draw and before readback, using the existing
privileged observer only. Public debug API must remain absent. Return exact
SHA256s, per-pair component/pixel counts, max/total absolute difference and
context attributes. Preserve two video-blur buffers only, within the existing
1MiB reply cap. Do not label an observed provider as proof of blur shader use.
The diagnostic validator accepts structurally valid differing observations
and reports them, but never returns pixel-equivalence or speed acceptance.

   draw errors, repeat-difference arithmetic and source-mutation rejection.
   Test serialized child source through the existing observer; test host
   capture identities, OFF receipts, raw-before-validation and RPC failures.
2. Run focused strict Node tests under 30 seconds and exact-file formatting
   under 60 seconds. Preserve failing-first results without claiming that a
   missing module is evidence of a browser defect.
3. Hash new siblings and all reused harness/package files. Check quiet laptop,
   available memory/disk, then one OFF capture in fresh owned roots. Existing
   browser installations are not closed or modified. External controller bound
   remains 220 seconds, SSH 240 seconds including preparation and cleanup.
4. Export only named evidence, not profiles/tokens. Verify raw file hashes and
   exact recorded PID absence. Analyse the complete matrix; if informative,
   repeat once in fresh roots, never rerun until green.

Unit tests establish bounded orchestration, not rendering correctness. A real
matrix distinguishes video-specific conversion from fixed-raster/filter
variation only within this fixture. Software/default differences alone do not
prove a bug or authorize enabling the candidate. Upstream source has both
accelerated and software blur routes; deployed branch/precision attribution
requires stronger evidence. Moving performance and import-failure/context-loss
gates remain separate work. No commits, staging, deployment or source-tree copies.
