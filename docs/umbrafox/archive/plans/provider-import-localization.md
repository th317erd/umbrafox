## Question And Contract

Does the OFF provider lose acceleration early in playback, and do equivalent
ON observations retain it? Source permits usage-profile refresh, allocation
failure and other paths; provider observations cannot distinguish those causes.
Do not disable refresh, force acceleration or treat software fallback as an
infrastructure failure in this new prospective diagnostic contract.

Keep the prior 48-second 1/4/4/1-copy workload, callback/deadline caps and fresh
R2 package. Add a private native observation immediately after an existing
draw batch: first 24 callbacks globally, plus the first callback of each phase.
At most 27 samples. Draw timing is recorded before observation. Owned page
CustomEvent detail is a bounded JSON string joining phase, phase callback
ordinal, global callback ordinal and callback time. No page-facing debug API,
extra draw, pixel readback, GPU wait or preference override.

Read native getDebugInfo(false) only for these samples, measure its elapsed
query time separately, bind exact canvas/document/preference/event identities,
and preserve the first observation failure. Existing before/after observations
remain false/true for ensureTarget; their observer effect remains documented.
Record actual frames/fallback-ratio/cache-miss-ratio preferences and user-value
flags before and after, require finite typed stable values, do not assume
defaults. Successful observation does not imply GPU command completion.

Validate every sample against the retained callback records and exact sampling
schedule. Missing, duplicate, reordered, foreign, malformed, overflowing or
unavailable observations reject. Initial acceleration is still required.
Final/intermediate software state is an explicit diagnostic classification,
never silently projected to acceleration. No-callback phases remain visible;
they provide no intermediate state evidence. Preference drift fails.

## Implementation And Verification

Use sibling provider-import workload/capture/driver/preflight/export files.
Retain prior files byte-for-byte. Prove inherited page behavior with AST
comparison after removing only the declared sample-event block; prove driver,
capture and transport equivalence with explicit bounded substitutions.

execution and native observer integration for exact joins, draw counts and

drift, missing target and native throws. Validate maximal data through the
actual 10000-node/one-MiB serializer. Corrupt each sampled field and schedule.
Use 10-second focused and 30-second combined watchdogs.

Then hash the new bundle and verify package/native/staged/previous-source
guards. Fresh laptop roots only; prior no-browser/build/resource preflight,
120-second capture, 220-second driver and 240-second SSH bounds remain.
Run one OFF diagnostic, inspect terminal/raw state and owned cleanup before
one ON. Failed admission/infrastructure stops without retry; observed natural
fallback is data under this new contract. Export only bounded non-secret
evidence and verify all recorded PIDs absent and package postchecks.

This pair localizes sampled state, not observer-free performance. Compare query
cost and timings descriptively; first-callback sampling changes observation
load. A separate balanced/minimal-observer control is required for performance
acceptance. Save next-step decisions from actual evidence without weakening
prior failures, fabricating cause or expanding deployment authority.

## Outcome

The planned OFF and ON diagnostics both completed and passed their explicit
observation contract. OFF transitioned from accelerated sample 9 to software
sample 10; the associated callback began 475 ms into the first phase. ON was
accelerated at all 27 samples. Actual profile thresholds were unchanged and
user-unset. Cleanup, package postchecks, native roots and exported hashes pass.
See `../reports/performance/2026-10-06-provider-import.md` for exact limits and
receipts. No further runtime is part of this localization phase; next define the
balanced minimal-observer gate without rewriting earlier failures.
