Reuse the two sealed cold-worker profiles and existing coverage/function contracts.
No browser, engine edit, build, installation, launcher, profile or index change.
The candidate remains uninstalled. This is a bounded offline continuation of
cold-worker-symbols, not a repeat of either failed debuginfod transfer.

Authenticate the debug key package over official Ubuntu HTTPS and its published
SHA256. Verify the signed ddebs InRelease, its exact compressed index SHA256,
the exact Mesa package SHA256/size, and the extracted ELF build ID. Extract only
the named debug entry; no package installation, scripts or global key changes.

The new query is a sibling of the frozen script: same profile/package hashes,
worker/clock/first-window counts, full-function self reconciliation, plus the
verified Mesa debug file hash, explicit local symbol directory and Mesa ID gate.
Separate new output/session names/ports. Retain missing-symbol failures.

Use the prior 150s work/180s server watchdog/210s outer bounds, command30s except
load60s, CLI cleanup15s and server5s. Samply8GiB address space,256MiB file size,
core0,two workers,private cache,no-open and explicit loopback symbol server.
Capture exact owned PID/socket absence; no SIGKILL or unrelated session stop.

Run existing focused contracts before loading, then baseline and candidate only
after cleanup passes. Recompute from supported exports, not custom raw-profile
parsing. Interpret driver names as sampled calls, not exact CPU/GPU durations
or proof of a shader-cache miss. Preserve earlier sealed evidence unchanged.
