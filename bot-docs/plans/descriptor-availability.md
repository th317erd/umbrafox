## Review Limits

Resource admission is host-local. Desktop native build/package actions use the
build-host compiler exclusion; laptop browser actions use the laptop's strict
browser/compiler/resource preflight. Do not treat an unrelated desktop test as
concurrent laptop workload. Source and harness hashes remain mandatory on both
paths. No overlapping owned build/browser work on one host, and no interference
with unrelated processes. This clarifies the scope of the existing preflight,
not a relaxation of the laptop measurement or cleanup checks.

The terminal test uses permanent RDD shutdown, not abnormal crash/restart.
Channel loss after successful admission, live-channel readback/allocation failure
and asynchronous GPU resource loss remain distinct risks. Do not claim universal
error parity, zero added overhead, physical smoothness or a YouTube fix.
